# Koenah hoodie storefront

A clean, responsive static storefront concept built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Unzip this folder.
2. Open `index.html` in a modern browser. No build step or server is required.

## Included
- Responsive landing page and product grid
- Brand styling based on the Koenah navy wordmark
- Product category filters
- Interactive demo shopping bag (add, remove, quantity, subtotal)
- Newsletter form interaction (demo only)
- Mobile navigation

## Before taking real orders
This is a visual/functional front-end prototype. It does **not** process payments, store orders, validate inventory, send newsletter emails, or connect to a fulfillment service. Replace the sample product details and illustrated product mockups with real photography, then connect a commerce platform such as Shopify, BigCommerce, or a custom checkout. Update contact, shipping, returns, privacy, and terms pages before launch.

## Customization
- `index.html`: text, product names, prices, sections
- `styles.css`: colors, typography, layout
- `script.js`: demo cart interactions
- `assets/koenah-logo.png`: logo image
